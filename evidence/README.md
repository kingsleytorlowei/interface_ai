# Evidence

One directory per run. Each holds a redacted `events.jsonl` (append-only, one event per line),
`result.json` (the typed run result), and `snapshots/` (redacted tree + text, and a screenshot)
wherever the engine stopped, asked for approval, or handed off. In events and results, the
run's sensitive inputs and outputs appear only as placeholders such as `«inputs.member_id»`.
Snapshots are scrubbed of those same values, but show whatever else was on screen (e.g. a
member name the capability never extracted); all data here is synthetic.

## Recorded runs (no LLM, no human)

Every run a script can reproduce, re-recorded from scratch with
`uv run python scripts/record_evidence.py` (starts its own mock banks; exits 1 if any run
doesn't give its expected result). Each directory also has `capability.json` (the exact
artifact replayed) and `scenario.json` (tenant, injected faults, artifact source).
